## 🔬 Research

**Testing Digital Systems Using Machine Learning: A Comparative Study** *(first author, manuscript in preparation)*
Al-Asaad Research Group, UC Davis

- Designed an automated RNN/LSTM framework to classify stuck-at faults (SA0/SA1) in digital circuits
- Generated training data by simulating faults on ISCAS'85 benchmark circuits with the ATALANTA ATPG tool
- Benchmarked LASSO, SVM, ANN, and LSTM models on accuracy, training time, noise robustness, and scalability
- Found that ANN and LSTM gave the strongest accuracy and noise resistance, while LASSO trained fastest with the smallest memory footprint

[📄 Read the paper](https://drive.google.com/file/d/1QUnFCwG9tUfN3Td5qpG70JzjES3rPZt5/view?usp=sharing) · [💻 Project code](https://github.com/lsverma0909/Fault_prediction_diagnosis)

**Earlier research**

- **Weimer Lab, UC Davis Veterinary Medicine:** programmed a JANUS liquid-handling robot and deployed ML tools (HAWK, Kover) with YAML configs for reproducible workflows
- **Jeong Group, UC Davis:** designed PCB-based wearable "electronic tattoo" sensors and applied DSP to physiological data
